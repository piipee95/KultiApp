# V5.4.0 — Desgaste por hora

Tarifa CLP/h configurable en cada impresora y conservada como copia en cada impresión. Las impresiones nuevas parten en $100/h; las guardadas antes de esta versión conservan cero para no alterar costos históricos. Elegir otra impresora copia su tarifa; editar su configuración después no modifica impresiones ya guardadas.

Cálculo por impresión: redondear a pesos (horas + minutos/60) × tarifa. Se suma al costo de impresión, separado de electricidad, filamento y otros costos. Es costo del lote: el costo unitario resulta de dividir el total entre la cantidad del producto. Cero desactiva el concepto. Los costos de desgaste manual existentes se conservan; si coexisten, se advierte para revisar duplicidad.

## Base de datos aplicada

Se aplicó la migración aditiva `docs/migraciones/SCHEMA_V54_0.sql` antes de publicar el cliente:
- `workspace_resources.wear_rate_per_hour`: tarifa configurable con valor inicial 100.
- `print_jobs.wear_rate_per_hour`: copia por impresión con valor histórico 0.
- Ampliación de la función existente `save_product_bundle_v5`, conservando firma, permisos y SECURITY INVOKER; inserta la nueva tarifa y mantiene la transacción de guardado.
- `product_cost_summary`: añade el desgaste calculado con el mismo redondeo; conserva SECURITY INVOKER y columnas públicas existentes.
- Permiso de escritura de la columna de tarifa del recurso, bajo las políticas RLS actuales. No se modifican políticas ni autenticación.

La migración se aplicó con autorización del dueño. Se verificó que los costos de los 12 productos anteriores, las políticas RLS y los permisos de ejecución de la función no cambiaran. La función y la vista conservan SECURITY INVOKER.

Las órdenes ya guardadas, sus reservas, pagos y costos no se recalculan. Se conserva el mecanismo existente para ofrecer la actualización de costo de pedidos después de guardar un producto. La estimación de fallas no incorpora esta tarifa nueva en esta entrega.

## Evidencia local

Node 24.22.1: ESLint y 45/45 suites con TZ=UTC aprobados. La suite nueva verifica horas/minutos (5:30 × 100 = 550), redondeo por impresión, reparto por cantidad, tarifa cero para datos anteriores, selección de impresora, copia de tarifa independiente de cambios futuros, recuperación del borrador y aviso de desgaste manual. Se ejecutó una transacción con rol authenticated: guardado de 5:30 h a 100/h, recuperación de tarifa, costo SQL de 550, independencia al cambiar la tarifa de la impresora y rechazo de tarifa negativa. Se revirtió toda la transacción; no se conservaron productos ni impresoras de prueba.

Revisión visual con datos ficticios y backend simulado: formulario de impresiones en escritorio claro y viewport móvil de 390 px oscuro. Se comprobó el recálculo visible de 550 a 1.100 al cambiar de 100 a 200 CLP/h. Esta revisión visual no sustituye un recorrido autenticado completo en producción.
